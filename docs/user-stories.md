# 사용자 스토리

<a id="u01"></a>

## U01 방문자의 가입과 로그인

- **누가 무엇을 왜:** 방문자는 자신의 관심 상품과 주문을 이용하기 위해 계정을 만들거나 로그인한다.
- **이용 순서:** 이메일 가입·로그인 또는 카카오 로그인 → 회원 기능 이용

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 처음 이용하는 방문자는 계정을 만든다. | `POST /api/members/register` | **201** — 서비스 로그인 토큰 |
| 회원은 이메일과 비밀번호로 로그인한다. | `POST /api/members/login` | **200** — 서비스 로그인 토큰 |
| 카카오로 이용하려는 방문자는 카카오 로그인 화면으로 이동한다. | `GET /api/auth/kakao/login` | **302** — 카카오 로그인 화면 URL |
| 카카오 로그인 후 서비스로 돌아온다. | `GET /api/auth/kakao/callback` | **400** — 카카오 인증 코드 누락 오류 |

<a id="u02"></a>

## U02 사용자의 상품 탐색

- **누가 무엇을 왜:** 사용자는 구매할 상품을 고르려고 상품 정보와 상품 옵션, 재고 수량을 살펴본다.
- **이용 순서:** 상품 찾기 → 상품 정보 확인 → 상품 옵션·재고 확인

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 사용자는 상품의 종류를 살펴본다. (선택) | `GET /api/categories` | **200** — 상품 분류 목록 |
| 사용자는 상품 목록에서 구매할 상품을 찾는다. | `GET /api/products` | **200** — 상품 목록 |
| 사용자는 고른 상품의 정보와 상품 가격을 확인한다. | `GET /api/products/{productId}` | **200** — 상품 정보 |
| 사용자는 상품 옵션과 재고 수량을 확인한다. | `GET /api/products/{productId}/options` | **200** — 상품 옵션 목록 |

<a id="u03"></a>

## U03 회원의 상품 주문

- **누가 무엇을 왜:** 회원은 선택한 상품을 구매하려고 상품 옵션과 주문 수량을 정해 포인트로 주문하고, 주문 내역을 확인한다.
- **이용 순서:** [상품 탐색](#u02)에서 옵션 선택 → 포인트로 주문 → 주문 내역 확인

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 회원은 상품 옵션과 주문 수량을 골라 포인트로 주문한다. | `POST /api/orders` | **201** — 주문 정보 |
| 회원은 자신의 주문 내역을 확인한다. | `GET /api/orders` | **200** — 주문 목록 |

> **이용 조건:** 주문에는 [로그인](#u01)과 충분한 보유 포인트가 필요하다.

<a id="u04"></a>

## U04 회원의 관심 상품 보관과 정리

- **누가 무엇을 왜:** 회원은 지금 구매하지 않는 상품을 나중에 다시 보기 위해 관심 상품에 담고, 필요 없어진 항목은 지운다.
- **이용 순서:** [상품 찾기](#u02) → 관심 상품 담기 → 다시 보기 → 필요 없어진 상품 삭제

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 나중에 다시 볼 상품을 관심 상품에 담는다. | `POST /api/wishes` | **201**, 같은 상품을 다시 담으면 **200** |
| 담아 둔 관심 상품을 다시 살펴본다. | `GET /api/wishes` | **200** — 관심 상품 목록 |
| 더 이상 보관하지 않을 관심 상품을 지운다. | `DELETE /api/wishes/{wishId}` | **204** — 응답 내용 없음 |

<a id="u05"></a>

## U05 관리자의 판매 상품 준비

- **누가 무엇을 왜:** 관리자는 고객이 상품을 고르고 주문할 수 있도록 상품 정보와 선택할 옵션, 재고 수량을 등록한다.
- **이용 순서:** 상품 분류 준비 → 상품 등록 → 옵션·재고 등록 → 등록된 상품 확인

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 필요한 상품 분류가 없으면 새로 만든다. | `POST /api/categories` | **201** — 상품 분류 정보 |
| 관리 화면으로 등록: 상품 추가 화면을 연다. | `GET /admin/products/new` | **200** — 상품 추가 화면 |
| 관리 화면으로 등록: 입력한 상품 정보를 저장한다. | `POST /admin/products` | **302** — 상품 관리 화면 URL |
| 직접 등록: 상품 정보를 보낸다. (관리 화면 대신 선택) | `POST /api/products` | **201** — 상품 정보 |
| 등록한 상품에 상품 옵션과 재고 수량을 추가한다. | `POST /api/products/{productId}/options` | **201** — 상품 옵션 정보 |
| 등록된 상품을 확인한다. | `GET /admin/products` | **200** — 상품 관리 화면 |

<a id="u06"></a>

## U06 관리자의 상품 정보 수정

- **누가 무엇을 왜:** 관리자는 고객이 올바른 정보를 보고 상품을 고를 수 있도록 상품이나 분류의 잘못된 내용을 수정한다.
- **이용 순서:** [등록된 상품 확인](#u05) → 수정할 정보 선택 → 변경 내용 저장

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 관리 화면으로 수정: 상품 수정 화면을 연다. | `GET /admin/products/{productId}/edit` | **200** — 상품 수정 화면 |
| 관리 화면으로 수정: 바꾼 상품 정보를 저장한다. | `POST /admin/products/{productId}/edit` | **302** — 상품 관리 화면 URL |
| 직접 수정: 바꾼 상품 정보를 보낸다. (관리 화면 대신 선택) | `PUT /api/products/{productId}` | **200** — 상품 정보 |
| 상품 분류를 고쳐야 하면 분류 정보를 수정한다. | `PUT /api/categories/{categoryId}` | **200** — 상품 분류 정보 |

<a id="u07"></a>

## U07 관리자의 판매 상품과 상품 옵션 정리

- **누가 무엇을 왜:** 관리자는 판매할 목록을 정리하기 위해 상품 옵션·상품·분류 중 불필요한 항목을 삭제한다.
- **이용 순서:** [등록된 상품 확인](#u05) → 지울 대상 선택 → 삭제

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 상품 옵션만 지우려면 해당 옵션을 삭제한다. | `DELETE /api/products/{productId}/options/{optionId}` | **204**, 마지막 상품 옵션이면 **400** |
| 관리 화면에서 상품을 삭제한다. | `POST /admin/products/{productId}/delete` | **302** — 상품 관리 화면 URL, 주문에 사용된 상품이면 **500** — 서버 오류 |
| 직접 요청으로 상품을 삭제한다. (관리 화면 대신 선택) | `DELETE /api/products/{productId}` | **204**, 주문에 사용된 상품이면 **500** — 서버 오류 |
| 필요 없어진 상품 분류를 삭제한다. | `DELETE /api/categories/{categoryId}` | **204**, 상품이 등록된 분류이면 **500** — 서버 오류 |

<a id="u08"></a>

## U08 관리자의 회원 포인트 충전

- **누가 무엇을 왜:** 관리자는 회원이 상품을 주문할 수 있도록 회원의 보유 포인트를 확인하고 충전한다.
- **이용 순서:** 회원과 보유 포인트 확인 → 포인트 충전 → 회원 목록으로 돌아가기

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 충전할 회원과 보유 포인트를 확인한다. | `GET /admin/members` | **200** — 회원 관리 화면 |
| 충전할 포인트를 입력하고 저장한다. | `POST /admin/members/{memberId}/charge-point` | **302** — 회원 관리 화면 URL |

<a id="u09"></a>

## U09 관리자의 회원 계정 관리

- **누가 무엇을 왜:** 관리자는 회원이 계정을 이용할 수 있도록 계정을 만들거나 정보를 수정하고, 필요한 경우 계정을 삭제한다.
- **이용 순서:** [회원 목록 확인](#u08) → 필요한 작업 선택 → 회원 목록으로 돌아가기

| 스토리 | API | 확인한 응답 |
| --- | --- | --- |
| 계정 생성: 회원 추가 화면을 연다. | `GET /admin/members/new` | **200** — 회원 추가 화면 |
| 계정 생성: 이메일과 비밀번호를 입력하고 등록한다. | `POST /admin/members` | **302** — 회원 관리 화면 URL |
| 정보 수정: 회원 수정 화면을 연다. | `GET /admin/members/{memberId}/edit` | **200** — 회원 수정 화면 |
| 정보 수정: 이메일과 비밀번호를 바꾸고 저장한다. | `POST /admin/members/{memberId}/edit` | **302** — 회원 관리 화면 URL |
| 계정을 삭제해야 하면 해당 회원을 삭제한다. | `POST /admin/members/{memberId}/delete` | **302** — 회원 관리 화면 URL |
