# 주문 흐름

- **관련 스토리:** [U03 회원의 상품 주문](../../user-stories.md#u03)
- **요청 API:** `POST /api/orders`
  - **로그인 정보:** 서비스 로그인 토큰을 요청 헤더의 `Authorization: Bearer <토큰>`에 담는다.
  - **주문 내용:** JSON에 상품 옵션 번호와 주문 수량을 필수로 담는다. 주문 메시지는 생략할 수 있다.
- **처리 순서:** 요청 확인 → 회원 확인 → 상품 옵션 확인 → 재고 차감 → 포인트 차감 → 주문 저장 → 카카오 알림 → 응답

주문 내용 예시 — 상품 옵션 번호 7을 2개 주문하고 메시지를 함께 보내는 경우:

```json
{
  "optionId": 7,
  "quantity": 2,
  "message": "감사합니다"
}
```

## 요청부터 응답까지

| 단계 | 확인하는 것 | 저장하는 것 | 응답 |
| --- | --- | --- | --- |
| 1. 요청 확인 | 로그인 정보·상품 옵션 번호가 있는지, 주문 수량이 1개 이상인지, 요청 형식이 올바른지 | 없음 | 잘못된 요청이면 **400** |
| 2. 회원 확인 | 서비스 로그인 토큰이 유효하고 해당 회원이 있는지 | 없음 | 회원을 확인하지 못하면 **401** |
| 3. 상품 옵션 확인 | 선택한 상품 옵션이 있는지 | 없음 | 없으면 **404** |
| 4. 재고 차감 | 재고 수량이 주문 수량 이상인지 | 주문 수량만큼 줄어든 재고 | 재고가 부족하면 **500** |
| 5. 포인트 차감 | 상품 가격 × 주문 수량이 1 이상이고 보유 포인트가 충분한지 | 계산한 금액만큼 줄어든 보유 포인트 | 금액이 0 이하이거나 포인트가 부족하면 **500** |
| 6. 주문 저장 | 주문 내용을 저장할 수 있는지 | 회원·상품 옵션·주문 수량·주문 메시지·주문 시각을 저장. 관심 상품은 삭제하지 않음 | 저장에 실패하면 **500** |
| 7. 카카오 알림 | 회원에게 카카오 연동 토큰이 있는지 | 없음. 토큰이 있으면 주문자 자신에게 알림을 보낸다. | 토큰이 없거나 알림 전송에 실패해도 완료 단계로 진행 |
| 8. 완료 | 추가 확인 없음 | 없음 | **201** — 주문 정보와 새 주문의 URL |

## 실패 응답과 남는 상태

| 실패 단계 | 실패 상황 | 응답 | 남는 상태 |
| --- | --- | --- | --- |
| 1. 요청 확인 | 로그인 정보 자체를 보내지 않음 | **400** — 잘못된 요청 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 1. 요청 확인 | 상품 옵션 번호 누락, 주문 수량 누락·0, 잘못된 요청 형식 | **400** — 잘못된 요청 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 1. 요청 확인 | 주문 수량이 음수 | **400** — 잘못된 요청 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 2. 회원 확인 | 서비스 로그인 토큰 오류 | **401** — 응답 내용 없음 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 2. 회원 확인 | 서비스 로그인 토큰 만료, 해당 회원 없음 | **401** — 응답 내용 없음 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 2. 회원 확인 | 회원 조회 중 오류 | **401** — 응답 내용 없음 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 3. 상품 옵션 확인 | 상품 옵션 없음 | **404** — 응답 내용 없음 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 3. 상품 옵션 확인 | 상품 옵션 조회 장애 | **500** — 서버 오류 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 4. 재고 차감 | 재고 부족 | **500** — 서버 오류 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 4. 재고 차감 | 재고 저장 중 오류 | **500** — 서버 오류 | 재고·포인트 변경 없음, 주문 생성 안 됨 |
| 5. 포인트 차감 | 포인트 부족 | **500** — 서버 오류 | **재고 감소 유지**, 포인트 변경 없음, 주문 생성 안 됨 |
| 5. 포인트 차감 | 계산한 금액이 0 이하 | **500** — 서버 오류 | **재고 감소 유지**, 포인트 변경 없음, 주문 생성 안 됨 |
| 5. 포인트 차감 | 포인트 저장 중 오류 | **500** — 서버 오류 | **재고 감소 유지**, 포인트 변경 없음, 주문 생성 안 됨 |
| 6. 주문 저장 | 주문 메시지가 저장 한도인 255자를 넘음 | **500** — 서버 오류 | **재고·포인트 감소 유지**, 주문 생성 안 됨 |
| 6. 주문 저장 | 주문 저장 중 오류 | **500** — 서버 오류 | **재고·포인트 감소 유지**, 주문 생성 안 됨 |
| 7. 카카오 알림 | 카카오 알림 전송 실패 | **201** — 주문 정보와 새 주문의 URL | 재고·포인트 감소, 주문 유지. 알림 실패 기록은 남기지 않음 |
