# 용어 사전

## 서비스의 주요 개념

| 한글명 | 영문명 | 이 서비스에서의 의미 |
| --- | --- | --- |
| 사용자 | User | 이 서비스를 이용하는 모든 사람. 방문자·회원·관리자를 모두 포함한다. |
| 방문자 | Visitor | 현재 로그인하지 않은 사용자. 계정이 있어도 로그인 전에는 방문자로 이용한다. |
| 회원 | Member | 이 서비스에 계정이 있는 사용자. 로그인 전에는 방문자로 이용하며, 주문·관심 상품 기능에는 로그인이 필요하다. |
| 관리자 | Administrator | 사용자 중 상품과 회원 정보를 관리하는 역할을 맡은 사람. 회원 여부·로그인 상태와는 다른 구분이며, 실제 담당자와 접근 권한은 확인이 필요하다. |
| 상품 | Product | 판매하는 물건의 기본 정보. 상품명과 상품 가격을 가지며, 상품 옵션을 골라 주문한다. |
| 상품 분류 | Category | 전자기기·패션·식품처럼 상품을 묶는 기준. 상품은 하나의 분류에 속한다. |
| 상품 옵션 | Product Option | 상품에서 구매할 종류를 고르는 단위. 예: 블루 / 256GB. 재고는 상품 옵션별로 관리한다. |
| 관심 상품 | Wishlist Item | 회원이 나중에 다시 보려고 담아 둔 상품. 상품 옵션이 아닌 상품을 담는다. |
| 재고 수량 | Stock Quantity | 상품 옵션별로 판매할 수 있는 남은 개수. 주문 수량만큼 줄어든다. |
| 상품 가격 | Unit Price | 상품 한 개의 가격. 같은 상품의 옵션들은 이 가격을 사용한다. |
| 주문 | Order | 회원이 상품 옵션 하나와 주문 수량을 정해 포인트로 구매한 기록. 여러 상품을 한 주문에 함께 담지는 않는다. |
| 주문 수량 | Order Quantity | 한 주문에서 선택한 상품 옵션을 구매하는 개수. |
| 주문 금액 | Order Total | 상품 가격 × 주문 수량. 이만큼 보유 포인트를 사용한다. |
| 주문 메시지 | Order Message | 회원이 주문할 때 선택해서 적는 말. 예: 감사합니다. |
| 카카오 알림 | Kakao Notification | 주문 내용과 주문 메시지를 담아 주문자 자신에게 보내는 알림. 카카오 연동 토큰이 있는 회원에게 전송을 시도한다. |
| 보유 포인트 | Point Balance | 회원이 주문에 사용할 수 있는 잔액. 주문 금액보다 부족하면 주문할 수 없다. |
| 충전 포인트 | Point Credit | 관리자가 회원의 보유 포인트에 더해 주는 양. |
| 사용 포인트 | Point Debit | 주문 금액만큼 보유 포인트에서 빼는 양. |
| 서비스 로그인 토큰 | Service Access Token | 이 서비스에 로그인한 회원임을 확인할 때 쓰는 값. 주문·관심 상품 요청에 함께 보낸다. |
| 카카오 연동 토큰 | Kakao Access Token | 카카오 로그인 과정에서 받는 값. 카카오 사용자 정보를 가져오거나 알림을 보낼 때 쓴다. |

## 같은 개념의 다른 이름

| 기존 표현 | 정한 한글명 | 정한 영문명 | 뜻 |
| --- | --- | --- | --- |
| 위시·`Wish`·관심 상품 | 관심 상품 | Wishlist Item | 회원이 나중에 다시 보려고 담아 둔 상품. |
| 카테고리·`Category`·상품 분류 | 상품 분류 | Category | 전자기기·패션·식품처럼 상품을 묶는 기준. |
| 옵션·`Option`·선택지·상품 옵션 | 상품 옵션 | Product Option | 한 상품에서 구매할 종류를 고르는 단위. 예: 블루 / 256GB. |
| 상품 이름·상품명 | 상품명 | Product Name | 상품에 붙인 이름. |
| 옵션 이름·옵션명 | 옵션명 | Option Name | 상품 옵션에 붙인 이름. |
| `Member.point`·포인트·보유 포인트 | 보유 포인트 | Point Balance | 회원이 주문에 사용할 수 있는 포인트 잔액. |

## 같은 이름의 다른 의미

| 기존 이름 | 사용되는 곳 | 정한 한글명 | 정한 영문명 | 뜻 |
| --- | --- | --- | --- | --- |
| `quantity` | 상품 옵션과 옵션 응답 | 재고 수량 | Stock Quantity | 상품 옵션별로 판매할 수 있는 남은 개수. |
| `quantity` | 주문과 주문 요청·응답 | 주문 수량 | Order Quantity | 한 번의 주문에서 구매하는 개수. |
| `price` | 상품과 상품·관심 상품 응답 | 상품 가격 | Unit Price | 상품 한 개의 가격. |
| `price` | 주문 처리 중 금액 계산 | 주문 금액 | Order Total | 상품 가격 × 주문 수량. 알림에서는 `totalPrice`와 ‘금액’으로 표현한다. |
| `amount` | 재고 차감 | 주문 수량 | Order Quantity | 주문 때문에 재고에서 빼는 개수. |
| `amount` | 회원 포인트 충전 | 충전 포인트 | Point Credit | 관리자가 회원에게 더해 주는 포인트. |
| `amount` | 주문 시 포인트 차감 | 사용 포인트 | Point Debit | 주문 금액만큼 보유 포인트에서 빼는 포인트. |
| `name` | 상품과 상품·관심 상품 응답 | 상품명 | Product Name | 상품에 붙인 이름. |
| `name` | 상품 분류와 분류 응답 | 분류명 | Category Name | 상품 분류에 붙인 이름. 예: 전자기기. |
| `name` | 상품 옵션과 옵션 응답 | 옵션명 | Option Name | 상품 옵션에 붙인 이름. |
| `id` | 상품 응답 | 상품 번호 | Product ID | 상품을 구별하는 번호. 관심 상품 응답에서는 `productId`로 표시한다. |
| `id` | 관심 상품 응답 | 관심 상품 번호 | Wishlist Item ID | 회원이 담아 둔 항목의 번호. 관심 상품 삭제에 쓰며 상품 번호와 다르다. |
| 토큰 | 서비스 로그인 응답의 `token` | 서비스 로그인 토큰 | Service Access Token | 이 서비스에 로그인한 회원임을 확인할 때 쓰는 값. |
| 토큰 | 카카오 응답의 `access_token`, 코드의 `accessToken`·`kakaoAccessToken` | 카카오 연동 토큰 | Kakao Access Token | 카카오에서 사용자 정보를 가져오거나 알림을 보낼 때 쓰는 값. |
| 메시지 | 주문 요청·응답의 `message` | 주문 메시지 | Order Message | 회원이 주문할 때 직접 적는 말. 예: 감사합니다. |
| 메시지 | 카카오로 보내는 알림 전체 | 카카오 알림 | Kakao Notification | 주문 내용과 주문 메시지를 담아 주문자 자신에게 보내는 알림. |
